## 一、🚨 新发现 P0（前 6 轮审查均未发现，ocr 独有）

### P0-OCR-1：`syncProgress` 云函数 `newerSide` 比较反转 → 跨设备同步数据丢失

**位置**：`cloudfunctions/syncProgress/index.js:153-155`

```js
// 云函数（错误）：
const newerSide = (cloudProgress.lastReadDate && localProgress.lastReadDate)
  ? (cloudProgress.lastReadDate >= localProgress.lastReadDate ? localProgress : cloudProgress)
  : (localProgress.lastReadDate ? localProgress : cloudProgress);
```

```ts
// 本地 storage.ts（正确）：line 141-143
const newerSide = (local.lastReadDate && cloud.lastReadDate)
  ? (local.lastReadDate >= cloud.lastReadDate ? local : cloud)
  : (local.lastReadDate ? local : cloud);
```

**问题**：云函数比较方向写反。当**云端进度较新**（cloud.lastReadDate > local.lastReadDate）时，条件 `cloud >= local` 成立 → 取 **localProgress（旧进度）**，云端新进度被本地旧进度覆盖。正确逻辑应取 `cloudProgress`。

**影响**：双端使用（手机 + 电脑）时，云端较新的阅读进度/连续天数被旧进度覆盖 = **跨设备数据丢失**。

**修复**（一行）：`cloudProgress.lastReadDate >= localProgress.lastReadDate ? cloudProgress : localProgress`

**验证**：Hermes 逐行对比 storage.ts（141-148 行）与 syncProgress/index.js（153-160 行），确认反转成立。

## 五、附：ocr 工具接入说明

```bash
# 服务器已装：/root/hermes-data/bin/opencodereview (v1.9.3)
export OCR_LLM_URL="https://opencode.ai/zen/go/v1"     # OpenAI 模式（不带 /v1 会 404）
export OCR_LLM_TOKEN="$OPENCODE_GO_API_KEY"
export OCR_LLM_MODEL="deepseek-v4-flash"
export OCR_USE_ANTHROPIC="false"
ocr scan --audience human --background "审查任务" --exclude '**/src/data/**'
```

**经验**：
- OpenAI 模式 URL 必须带 `/v1`；Anthropic 模式 URL 不带（拼 `/v1/messages`）
- 大数据文件（如 509 条数据 blob）会触发 token 阈值告警 + 极慢，用 `--exclude` 排除
- 119 文件全量审查约 25-35 分钟（网关响应 30-60s/次）
